# Бот-расписание ВГАТК

Как это работает:
1. Ты (админ) отправляешь боту фото расписания в личку.
2. Бот отправляет фото в Gemini Vision с промптом-инструкцией, получает
   структурированный JSON и сохраняет его в базу (по каждой группе отдельно).
3. Любой человек открывает Mini App внутри Telegram-бота, выбирает свою
   группу в выпадающем списке и видит актуальное расписание текстом.

## Структура проекта

```
vgatk_bot/
  app.py            — FastAPI-сервер: и бот (через webhook), и API, и раздача мини-аппа
  db.py             — работа с SQLite (хранение расписания)
  llm_parser.py     — промпт и вызов Gemini Vision для распознавания фото
  miniapp/index.html — сам мини-апп (выбор группы + просмотр расписания)
  requirements.txt
  .env.example
```

## Шаг 1. Получи токен бота

Напиши @BotFather в Telegram → `/newbot` → следуй инструкциям → получишь `BOT_TOKEN`.

## Шаг 2. Получи бесплатный ключ Gemini

Зайди на https://aistudio.google.com/apikey, создай ключ — это `GEMINI_API_KEY`.
У Gemini 2.0 Flash щедрый бесплатный лимит запросов в день, для одного колледжа
этого более чем достаточно (фото загружается редко, не каждую секунду).

## Шаг 3. Узнай свой Telegram ID

Напиши боту @userinfobot — он покажет твой числовой ID. Впиши его в `ADMIN_IDS`
в `.env` — только этот аккаунт (или несколько через запятую) сможет
загружать/обновлять расписание.

## Шаг 4. Настрой .env

Скопируй `.env.example` в `.env` и заполни:
- `BOT_TOKEN`
- `ADMIN_IDS`
- `GEMINI_API_KEY`
- `WEBHOOK_SECRET` — любая случайная строка, например `openssl rand -hex 16`
- `BASE_URL` — заполнишь после деплоя (шаг 5), это публичный адрес сервиса

## Шаг 5. Бесплатный хостинг — Render.com

Render подходит лучше всего для этого проекта: одна публичная HTTPS-ссылка
на весь сервис (нужна и боту, и мини-аппу), Python поддерживается "из коробки",
кредитная карта не требуется.

1. Залей проект на GitHub (обычный публичный или приватный репозиторий).
2. Зайди на https://render.com → New → Web Service → подключи репозиторий.
3. Настройки:
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: Free
4. В разделе Environment добавь все переменные из `.env` (кроме `BASE_URL` — 
   его пока оставь пустым).
   
   ⚠️ Важно: в проекте есть файл `runtime.txt` с указанием `python-3.11.10`.
   Render читает его автоматически и ставит именно эту версию Python.
   Без него Render может выбрать слишком новую версию Python (например 3.14),
   под которую у части зависимостей (`pydantic-core` внутри aiogram) ещё
   нет готовых бинарных пакетов — тогда сборка упадёт с ошибкой компиляции
   через Rust/maturin. Если это всё равно произошло — убедись, что
   `runtime.txt` лежит в корне репозитория (рядом с `requirements.txt`),
   и сделай Manual Deploy → Clear build cache & deploy.
5. Нажми Create — Render даст тебе адрес вида `https://vgatk-bot.onrender.com`.
6. Впиши этот адрес в переменную `BASE_URL` в настройках сервиса на Render
   и передеплой (Manual Deploy → Deploy latest commit).

Важный нюанс бесплатного тарифа Render: сервис "засыпает" после 15 минут
без запросов и просыпается около минуты при следующем обращении. Для бота
это не критично — Telegram просто чуть дольше ждёт ответ на первое
сообщение после простоя, но обновление расписания и открытие мини-аппа
всё равно сработают.

Альтернативы, если Render не подойдёт: Railway.app, Fly.io — там тоже есть
бесплatные лимиты, но условия периодически меняются, так что перед выбором
стоит свериться с их актуальными тарифами.

## Шаг 6. Подключи Mini App к боту

В @BotFather:
1. `/mybots` → выбери своего бота → **Bot Settings** → **Menu Button**
2. Укажи в качестве URL твой `BASE_URL` (тот же адрес, что и в `.env`)
3. Название кнопки, например: `📅 Расписание`

Теперь у всех пользователей бота слева от поля ввода появится кнопка,
открывающая мини-апп.

## Локальный запуск (для теста, до деплоя)

Локально webhook не заработает (Telegram нужен публичный https), поэтому
для локальной проверки удобно временно пробросить порт через ngrok:

```bash
pip install -r requirements.txt
ngrok http 8000        # получишь https-адрес, впиши его в BASE_URL
uvicorn app:app --reload --port 8000
```

## Что можно улучшить дальше

- Не хранить фото и распознавание в одном synchронном хендлере — вынести
  вызов Gemini в фон, если фото большие и распознавание долгое.
- Добавить подтверждение админу перед публикацией (сейчас расписание
  обновляется сразу после распознавания).
- Хранить историю версий расписания, а не только последнюю.
